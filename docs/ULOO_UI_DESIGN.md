# ULOO 界面设计交付说明

更新：2026-10-08。页面地图与状态仍以 ULOO_UI_BLUEPRINT.md 为准。

## 视觉与布局

- 使用已有驭龙标识与 Dify 主题 token；浅色工作台、蓝色主操作，兼容深色模式。
- 桌面 240–256px 常驻侧栏，工作／运行与资产／资源／集成分组。
- 统一顶部模块路径、新任务入口和运行环境入口；不伪造绿色就绪状态。
- 内容最大宽度 1280px，页面标题与操作区分隔，卡片使用统一圆角与留白。
- 窄屏保留横向可滚动导航；表单与主操作自动换行，长对象名称可折行。

## 页面设计结构

| 页面 | 主区域 | 辅助区域 |
|---|---|---|
| 任务入口 | 四步骤导览、目标输入、团队选择、规划按钮 | 示例任务、最近任务 |
| 全部任务 | 筛选与任务列表 | 状态、进入工作台 |
| 任务工作台 | 规划／确认／执行／交付统一阶段条 | 团队、来源、运行链接 |
| 运行详情 | 有序事件、最终输出 | 来源任务、团队、用量、错误 |
| 智能体 | 角色配置、列表与详情 | 对话调试、校验与版本 |
| 团队 | 团队卡片与成员配置 | 协作模式、Leader、限制 |
| 交付成果 | 成果列表与内容详情 | 来源任务／运行 |
| 记忆中心 | 记忆列表、内容与作用域 | 来源、审核与版本结构 |
| 运行环境 | 实际能力和依赖检查 | 配置缺失说明 |
| Studio | 集成说明与输入输出结构 | 安装状态与 Studio 入口 |

## 真实性与验收边界

正式页只使用真实接口；预览页明确标记演示身份并维持预览路由。
页面结构存在不等于对应后端已完成。Teams 正式配置、成果、Memory、Studio、SSE 等仍按 TODO 逐项接入。
本轮完成公共框架、入口与阶段条视觉统一，不更换登录体系、不新建工作流画布、不增加模型调用。
